# Post Management App
- [Deployed](https://elevate-task-xi.vercel.app/) 
A React-based posts management application built as a frontend assignment using the JSONPlaceholder API.
The Application allows users to browse posts, search and filter them by author, navigate through paginated results, view post details, and create new posts through a validated form.

## How to install dependencies ?
npm install

## How to run the project locally ?
git clone
npm install
npm run dev
